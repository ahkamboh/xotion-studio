# xotion brand assets

| File | Use |
|---|---|
| `xotion-logo.png` | full lockup (mark + wordmark + tagline) on dark — README / hero |
| `xotion-icon.png` | app icon (glowing gradient "x" on dark rounded tile), transparent |
| `xotion-mark.svg` | scalable app-icon mark (dark tile + gradient x) |
| `xotion-mark-flat.svg` | scalable mark, transparent (just the gradient x) |

**Colors:** gradient `#5cffd0 → #3fa9ff → #7b5cff` on near-black `#080b18` / tile `#0a0f22→#16203f`.
**Type:** Sora 800 (wordmark), Inter 500 (tagline). The "x" = the mark; the caret "|" = the prompt.
PNGs are rendered from HTML via HyperFrames (`projects/_logo`, `projects/_icon`) — re-render to restyle.
