# Agent Topology Audit — Proposal (NOT YET APPLIED)

> Status: **pending user approval.** Generated by a multi-agent audit workflow
> (66 agents, 2.87M tokens, 56 findings → 7 survived adversarial verification).
> Do NOT apply any of this until the user explicitly says to.

## Problem
`qa-visual` carries **27 responsibilities** mixing 3 unrelated QA classes
(broken-output correctness + editorial richness + motion richness). Quality
leaks because a black frame hides among 27 sub-checks and "shipped but flat"
soft-passes. Plus several agent overlaps (two owners for one job) and a
serial pipeline that leaves easy parallelism on the table.

User's governing principle: *"agent do one work only — if one agent does more
than one work, somewhere quality will be downgraded."*

## 3 new agents (each ONE responsibility)

### qa-correctness
- **Job:** Verify the render is not mechanically broken (cut-off, black, overlap, stuck, miscentered, off-beat).
- **Tools:** Bash, Read
- **Reads:** the qa-frames manifest the Director extracts ONCE (never re-runs qa-frames.py).
- **Output:** `work/qa-correctness.json` (PASS/FAIL per scene per gate).
- **Routes FAIL to:** sync-master (timing) / colorist (grade) / assembler (assembly) / motion-builder (text/center/edges).
- **Never:** check richness/contrast/hero-scale (qa-richness's job); modify files; block on license.

### qa-richness
- **Job:** Verify editorial + motion density (type contrast ≥8x, accent ≤1/scene, chrome present, number stability, safe-area, two-beat reveal, not-static, textured bg, ≥5 layers, depth shadows, one hero-scale anchor).
- **Tools:** Bash, Read
- **Reads:** same shared qa-frames manifest.
- **Output:** `work/qa-richness.json`.
- **Routes FAIL to:** motion-builder only (sole owner of richness application).
- **Never:** check broken output (correctness's job); modify composition files; decide which rules apply (those live in CLAUDE.md / docs/richness.md).

### license-auditor
- **Job:** Verify every shipped asset has a valid `.license.json` before delivery runs.
- **Tools:** Bash, Read, Grep
- **Does:** parse index.html for `<video>/<audio>/<img>/<source>/srcset/url()` + work/*.json manifests; require each asset have a sibling `.license.json` with license in {pixabay-content-license, cc0, public-domain, royalty-free-stock, self-generated, user-provided-attested}; cover synth SFX (`self-generated`), fonts (`assets/fonts/LICENSES.json`), user footage (`--attest-license` or fail closed); emit `work/license-manifest.json`; exit non-zero on any miss.
- **Routes FAIL to:** Director (surface missing asset path).
- **Never:** auto-fix/add licenses; re-fetch; interpret unknown licenses (fail closed); run after delivery.
- **New script needed:** `scripts/license-audit.sh`.

## Split
- **qa-visual → qa-correctness + qa-richness.** Each fails independently and routes to a different fixer. Both consume ONE qa-frames.py invocation (Director extracts once), enabling parallel execution.

## New pipeline (3 fan-out points)

```
Director (Steps 1-5: UNDERSTAND → ANALYZE → DECIDE → PLAN → CONFIRM)
   │
   ├─ FAN-OUT 1: art-director ∥ scriptwriter        (script needs only duration, not palette)
   │    └ BARRIER: style.json + script.txt
   │
   ├─ FAN-OUT 2: audio-engineer ∥ stock-scout       (no shared inputs)
   │    └ BARRIER: vo.json + assets/stock/*
   │
   ├─ sync-master (canonical scene boundaries from voice — runs FIRST)
   ├─ b-roll (broll-plan.json — no index.html writes)
   ├─ motion-builder (index.html + XChart + GLTFLoader + BROLL_WINDOWS + beats snap + motion-hits.json)
   ├─ audio-engineer (SFX placement pass — reads motion-hits.json, re-master)
   ├─ assembler (montage + overlay + mux + cutaways)
   ├─ captioner (captions.js)
   ├─ colorist (grade + bloom + grain + vignette)
   │
   ├─ Director runs qa-frames.py ONCE → work/qa-frames-manifest.json
   │
   ├─ FAN-OUT 3: qa-correctness ∥ qa-richness ∥ qa-audio ∥ license-auditor
   │    └ BARRIER: all 4 PASS
   │
   ├─ Director Step 7 acceptance review
   └─ delivery (Stage A parallel; Stage B after export-subs)
```

**FAIL routing:** qa-correctness→sync-master/colorist/assembler/motion-builder · qa-richness→motion-builder · qa-audio→audio-engineer · license-auditor→Director.

## Expected impact
- **Speed: 30–45% faster** (~3–5 min off an 8–12 min job). QA fan-out is highest-leverage (also kills duplicated frame extraction).
- **Quality:** broken-frame + flat-look each become dedicated blocking gates; single writer for index.html; single source of truth for scene timing; .glb pipeline closed; SFX lands on real motion hits; license exposure eliminated.

13 → 15 (split qa-visual into 2, add license-auditor; net +2). Plus 5 edits + CLAUDE.md pipeline rewrite + new `scripts/license-audit.sh`.
