# HyperFrames block registry — 111 ready-made blocks

Install with `scripts/add-block.sh <name>` (= `npx hyperframes add <name>`). Writes block files into
the project + prints an include snippet. **Use these before hand-building** — transitions, data viz,
maps, caption styles, social overlays are all here.
